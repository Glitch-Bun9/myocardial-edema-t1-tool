模块1：输入您测量的 Native T1 和/或 ECV 来预测心肌水肿

请阅读使用须知

使用说明

  1. 本模块仅供科研参考，不能用于临床诊断或替代完整的心脏磁共振评价！
  2. 本研究模型基于西门子和飞利浦 3.0 T MRI 系统采集的数据建立。T1 mapping 采用 modified Look-Locker inversion recovery（MOLLI）gradient-echo sequence，T2 mapping 采用 gradient-echo sequence with T2 preparation 或 six-echo gradient spin-echo（GraSE）sequence。其他设备、磁场强度或序列获得的数据建议使用模块2建立本中心拟合关系。
  3. 本模块主要用于 T2 成像质量欠佳时帮助判断该区域是否为假阳性水肿，或在临床高度提示心肌水肿时评估 Native T1 与 ECV 的升高程度是否支持水肿表现。
  4. 前两步所选的间质纤维化背景及 LGE 情况将决定所采用的研究阈值，并直接影响预测结果，请结合完整的临床与影像资料谨慎选择。

模块2：构建您的水肿心肌专属虚拟 T2 value 预测模型

请阅读使用须知

使用说明

  1. 本模块仅供科研参考，不能用于临床诊断，也不能替代实际 T2 value 测量！
  2. 不同中心、磁场强度、设备型号及扫描序列获得的 Native T1 与 T2 value 可能具有不同的正常参考范围。本模块可以基于您输入的数据构建您专属的水肿心肌 Native T1–T2 value 回归模型。
  3. 输入足够的水肿心肌 Native T1–T2 value 配对数据后，可生成适用于您中心数据的线性拟合公式及模型评估结果。
