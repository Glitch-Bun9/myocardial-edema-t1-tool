关于本研究工具

本工具仅供科研参考。所有结果不能用于临床诊断，也不能替代实际测量！

注：本工具不适用于合并以下疾病的患者：遗传性心肌病、肥厚型心肌病拟表型疾病、扩张型心肌病、铁沉积、羟氯喹心肌病等特殊情况。

使用须知

基于前期研究发现的心脏磁共振 Native T1、ECV 与 T2 value 之间的关系，我们开发了这一用于辅助预测心肌水肿的科研工具。本工具包含两个模块。详细说明如下：

模块1：基于 T1 参数辅助预测心肌水肿

应用场景：当 T2 成像质量欠佳时，辅助判断局部区域是否为假阳性水肿，或在临床强烈提示心肌水肿时，Native T1 和 ECV 的升高程度是否支持心肌水肿表现。请注意本部分预测模型基于西门子和飞利浦 3.0 T MRI 系统采集的数据建立（T1 mapping 采用 modified Look-Locker inversion recovery（MOLLI）gradient-echo sequence，T2 mapping 采用 gradient-echo sequence with T2 preparation 或 six-echo gradient spin-echo（GraSE）sequence）。

输入：使用者首先评估待测心肌是否可能存在间质纤维化，并选择测量区域是否存在延迟强化（LGE），随后输入一个或多个感兴趣区（ROI）的 Native T1 和/或 ECV。工具支持逐个添加或批量粘贴多个 ROI。

输出：工具分别根据 Native T1、ECV 及二者的组合评分进行判断。不同的间质纤维化背景和 LGE 情况对应不同的研究阈值，结果显示各项参数预测结果是否支持心肌水肿。

说明：由于间质纤维化背景有时难以直接确定，工具提供了可以初步评估患者心肌间质纤维化可能性的功能区，综合参考 UK Biobank 研究参考上限最大室壁厚度研究参考上限男性：1.299 ×（3.90 × BSA + 0.03 × Age + 2.06）女性：1.249 ×（3.20 × BSA + 0.07 × Age − 0.34）Hunain S, Rhodri D, Joao A, et al. Beyond 15 mm: towards a new personalised, AI-measured definition of hypertrophic cardiomyopathy using an age-, sex-, and body surface area-adjusted approach. Heart. 2023;109(Suppl 1):A3–A4.点击可在新窗口查看原文、体重指数及相关临床背景因素。使用者应结合评估结果、完整临床资料及心脏磁共振表现，最终选择待测心肌是否有间质纤维化。

Native T1、ECV 及 Native T1 + ECV 组合评分的阈值均来源于前期研究的 ROC 分析，最佳阈值采用 Youden 指数确定。组合评分由包含 Native T1 和 ECV 的多变量 Logistic 回归模型获得，计算方式为 Score = β₁ × Native T1 + β₂ × ECV，具体阈值与各场景对应的评分公式见下表。仅输入 Native T1 时，工具仅输出基于 Native T1 的结果。同时输入 Native T1 和 ECV 时，工具输出三种方式的结果。当 Native T1 达到相应水肿阈值时，工具还会根据前期研究获得的稳定线性关系提供虚拟 T2 value，计算方式为 T2 value = −43.52 + 0.06795 × Native T1。该线性关系及其跨中心应用方式详见模块2。

模块2：构建专属水肿心肌虚拟 T2 value 预测模型

应用场景：我们先前的研究结果表明，水肿心肌的 Native T1–T2 value 具有较强的线性正相关。考虑到不同中心、磁场强度、设备型号及扫描序列之间的跨中心差异，本模块可帮助拟合用户专属的水肿心肌 Native T1–T2 value 线性关系，并据此预测本中心的虚拟 T2 value。

输入：输入一个或多个水肿心肌 ROI 的 Native T1。如有对应的 T2 value 实测值，可同时输入。工具支持逐个添加或批量粘贴多个 ROI。

输出：工具首先根据本研究默认线性关系生成用户输入的各个 ROI 的虚拟 T2 value。若同时输入 T2 value 实测值，还会显示实测值与预测值的差值。仅当用户输入的完整 Native T1 和 T2 value 实测值配对数据超过 10 对时，才可进一步拟合基于用户输入数据的 Native T1–T2 value 线性关系，并输出对应的拟合公式、R²、样本量及相应图形。

说明：基于先前数据拟合的默认 Native T1–T2 value 线性关系为 T2 value = −43.52 + 0.06795 × Native T1（R² = 0.718，n = 99，见下图）。对于用户自行建立的模型，输入数量充足且完整、准确的配对数据，有助于获得更可靠的拟合与预测结果。请注意本模块生成的虚拟 T2 value 仅供科研参考，不能替代实际 T2 value 测量或用于临床诊断。
