About This Research Tool

For research use only. Results must not be used for clinical diagnosis or in place of direct measurement!

This tool is not intended for patients with genetic cardiomyopathy, phenocopies of hypertrophic cardiomyopathy, dilated cardiomyopathy, iron overload, hydroxychloroquine cardiotoxicity, or similar conditions.

Instructions

We developed this research tool from our earlier work on the relation between CMR native T1, ECV, and T2 values. It is designed to support the assessment of myocardial edema and includes two modules.

Module 1: T1-Based Assessment of Myocardial Edema

Application: When T2 image quality is poor, this module can help assess whether an apparent area of edema may be false positive. When clinical findings strongly suggest myocardial edema, it can also show whether the rise in native T1 and ECV supports edema. The model was developed with data from Siemens and Philips 3.0 T MRI systems. T1 mapping used a modified Look-Locker inversion recovery (MOLLI) gradient-echo sequence. T2 mapping used either a gradient-echo sequence with T2 preparation or a six-echo gradient spin-echo (GraSE) sequence.

Input: First assess whether the target myocardium may have interstitial fibrosis and select its late gadolinium enhancement (LGE) status. Then enter native T1 and/or ECV for one or more regions of interest (ROIs). You can add ROIs one at a time or paste several rows.

Output: The tool assesses native T1, ECV, and a combined score. The research cutoffs differ by fibrosis background and LGE status. Each result shows whether the entered value supports myocardial edema.

Notes: Interstitial fibrosis may not always be clear. The native T1, ECV, and combined-score cutoffs came from ROC analyses in our earlier study. Optimal cutoffs were selected with the Youden index. The combined score came from a multivariable logistic regression model with native T1 and ECV: Score = β₁ × Native T1 + β₂ × ECV. The cutoffs and formulas for each setting are shown below. If only native T1 is entered, the tool reports the native T1 result only. If both native T1 and ECV are entered, it reports all three results. When native T1 reaches the edema cutoff, the tool also gives a virtual T2 value based on the relation found in our earlier study: T2 value = −43.52 + 0.06795 × Native T1. Module 2: Build a Local Virtual T2 Model for Myocardial Edema

Application: Our earlier study found a strong positive linear relation between native T1 and T2 values in edematous myocardium. Normal ranges can differ by center, field strength, scanner, and sequence. This module can fit a local native T1–T2 relation for edematous myocardium and use it to estimate virtual T2 values.

Input: Enter native T1 for one or more ROIs with suspected or confirmed myocardial edema. You may also enter the measured T2 value for each ROI. ROIs can be added one at a time or pasted in several rows.

Output: The tool first estimates a virtual T2 value for each ROI with the default study equation. If a measured T2 value is entered, it also shows the difference between measured and predicted values. With more than 10 complete native T1–T2 pairs, the tool can fit your own linear model and report its equation, R², sample size, and plot.

Notes: The default relation from our earlier data is T2 value = −43.52 + 0.06795 × Native T1 (R² = 0.718, n = 99, shown below). A larger set of complete and accurate paired values will give a more reliable local model. Virtual T2 values are for research use only. They must not replace measured T2 values or be used for clinical diagnosis.
